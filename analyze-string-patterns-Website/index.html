What it counts

The tool identifies and counts occurrences of common suspicious string patterns within a given text file, using regular expressions. Usage, as the README gives it: python3 main.py FILEPATH [-o OUTPUT] [-l LEVEL]. Its one requirement is pandas>=2.1.0.

Parameters

ParameterWhat the README says
FILEPATHpath to the text file to analyze.
-hshow help message and exit.
-o, --outputpath to save the analysis results as a CSV file (optional). With -o, the CSV has two columns, Pattern and Count.
-l, --log_levellogging level: DEBUG, INFO, WARNING, ERROR, or CRITICAL. Default: INFO.

Verified behavior and stated limits

A sample containing one IP address, one email address, and one URL reported a count of 1 for each of those three patterns and 0 for Hex Encoded, MD5 Hash, SHA1 Hash, SHA256 Hash, and Base64 Encoded. The verified sample counts stand as tested evidence, three patterns found once each and five not found at all in the sample that was run. The tally is one sample result, not a promise about other files.
