Log entry four: the run and its arguments

python3 main.py FILEPATH [-o OUTPUT] [-l LEVEL]

FILEPATH is the path to the text file to analyze.

-h shows the help message and exits.

-o, also written --output, gives the path to save the analysis results as a CSV file, and is optional.

-l, also written --log_level, sets the logging level to one of DEBUG, INFO, WARNING, ERROR, or CRITICAL, with INFO as the default.

Log entry five: outputs and failure, closing the log
